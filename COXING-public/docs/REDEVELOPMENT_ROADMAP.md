# 개발 재개 계획

2025-12-13 기준 개발 상태를 보존하면서 동일 프로젝트의 개발을 다시 진행할 예정입니다. 아래 과업은 계획이며, 이번 공개 준비 과정에서 구현하지 않았습니다.

## 1. 기준 동작 복원

기존 환경의 의존성·씬 연결·카메라 권한·빌드 대상을 확인합니다. Unity 버전, 기기와 OS, 컴파일 결과, 실행 여부를 기록합니다. ID 0/1 단독·동시 추적과 표시 모드 전환을 확인합니다.

## 2. 소실 처리 수정

검출이 0개인 준비 완료 프레임에도 소실 타이머가 갱신되도록 최소 변경합니다. 한 마커만 가리는 경우, 전체를 가리는 경우, 다시 보여주는 경우를 각각 비교합니다.

## 3. 비용을 측정하며 줄이기

- 같은 카메라 프레임의 중복 검출 방지.
- 디버그 표시가 꺼져 있을 때 선 그리기와 결과 텍스처 복사 생략.
- 반복 할당과 임시 버퍼 수명 점검.
- 영상 해상도와 보간 계수를 동일 조건에서 비교.

기준 FPS·CPU/GPU 시간·추종 지연·떨림·검출 성공률이 아직 없어 개선 비율을 제시하지 않습니다. 검출 주기를 줄여도 표시와 소실 처리는 계속 갱신해야 합니다.

## 4. 별도 실험

기준 복원 후 최신 카메라 API, SDK 전환, GPU 전처리·비동기 읽기·작업 스레드를 개별 비교합니다. API 전환만으로 성능이 향상됐다고 판단하지 않고 영상과 카메라 자세의 시간 정합, 결과 지연, 재인식과 장시간 실행도 확인합니다.

원본을 유지하고 한 번에 한 변경을 평가합니다. 검증 후 공개용 설명과 코드도 별도로 갱신하며, 전체 개발 폴더를 그대로 공개 범위에 추가하지 않습니다.
