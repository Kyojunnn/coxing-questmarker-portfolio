# 문제 해결 및 재현 계획

아래 내용은 정적 검토와 과거 오류 보고를 바탕으로 합니다. 이번 공개 준비에서 오류를 재현하거나 해결한 것은 아닙니다.

## 모든 마커가 사라졌을 때 퇴장 갱신 중단 가능성

`ArUcoMarkerTracking.EstimatePoseCanonicalMarker`는 검출 코너가 0개이면 반환합니다. 소실 타이머와 퇴장 갱신은 그 뒤에 있어, 전체 검출이 끊기면 실행되지 않는 흐름입니다.

재현 시 두 마커를 보인 후 하나만 가리는 경우와 두 개 모두 가리는 경우를 비교합니다. 준비가 완료된 프레임의 검출 0개와 카메라 준비 실패를 구분하고, 자세 계산과 표시 상태 갱신의 분리를 검토합니다. 이 수정은 아직 적용하지 않았습니다.

## 콘텐츠가 보이지 않을 때

카메라 디버그 뷰가 초기 모드입니다. A 버튼 전환과 Renderer 상태를 먼저 확인합니다. 이후 ID 매핑, 실제 인쇄된 마커 길이, 좌표축과 모델 피벗을 점검합니다. 가상 물체가 숨겨진 경우를 검출 실패로 판단하지 않습니다.

## 한글과 Bounds 경고

과거에 한글 네모 표시와 `Invalid AABB inAABB` 오류가 보고됐습니다. 폰트 파일이 존재하는 것만으로 해결됐다고 판단하지 않습니다. 권한이 확보된 폰트와 TMP 글리프·fallback·atlas, UI RectTransform/Bounds를 각각 점검합니다. 기존 폰트와 모델은 이 준비본에서 제외했습니다.

## 의존성 및 빌드

이 자료만으로는 Unity 컴파일·실행이 되지 않습니다. OpenCVForUnity, Meta 샘플의 WebCamTextureManager와 카메라 유틸리티, OVRInput/OVRPlugin 등이 외부에 있습니다. 스크립트 파일 부재와 외부 패키지 미설치를 구분합니다.

보존 개발본의 EditorBuildSettings에 나열된 씬은 비활성 상태였으므로 실제 Build Profile의 씬 목록을 확인해야 합니다. 공개 준비본에는 씬이나 Build Profile을 포함하지 않았습니다.

## 최소 회귀 확인

| 조건 | 확인할 결과 |
|---|---|
| 권한 허용 후 시작과 A 버튼 전환 | 카메라 뷰·콘텐츠 표시 구분 |
| ID 0/1 각각 및 동시에 표시 | 해당 오브젝트 연결·이동·회전 |
| 한 마커만 가리기 / 전부 가리기 | 대상별 퇴장과 전체 검출 0개 처리 |
| 소실 후 재등장 | 활성 상태·원래 스케일 복원 |
| 인트로 표시 | 한글 출력·페이드·Bounds 경고 |

이 표는 테스트 계획입니다. 통과 결과나 성능 수치는 아직 없습니다.
