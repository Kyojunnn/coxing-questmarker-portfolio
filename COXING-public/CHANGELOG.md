# 변경 기록

## 2026-11-26 — 선별 공개 준비

- 주요 C# 3개를 보존 개발본에서 내용 변경 없이 복사.
- 공개용 개요·구조·상태·문제·의존성·재개 계획을 한국어로 작성.
- 기반 프로젝트와 Meta 샘플의 출처 및 MIT 고지 보존.
- 개인 경로·연락처·원본 대화·기존 Git 이력·구매 플러그인·권리 미확인 에셋을 준비본에서 제외.
- Unity 컴파일·기기 실행·런타임 수정·GitHub 게시는 이번 준비에 포함하지 않음.
