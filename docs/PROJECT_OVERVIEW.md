# 프로젝트 개요

CO·XING QuestMarker Demo는 현실 소품과 가상 캐릭터를 연결하는 XR 프로토타입입니다. 물건의 마커가 보이면 대응하는 3D 오브젝트를 배치하고, 물건을 움직였을 때 위치와 회전을 갱신하는 코드 경로가 있습니다. 목표는 물건을 들고 움직이며 인형놀이처럼 장면을 구성하는 경험입니다.

## 기반과 프로젝트 구성

| 구분 | 설명 |
|---|---|
| 기반 샘플 | QuestArUcoMarkerTracking, Meta Passthrough Camera API Samples |
| 개발본에서 확인한 구성 | 마커 ID 0/1과 서로 다른 오브젝트 연결, 스케일 등장/퇴장 처리, 인트로 UI와 표시 모드 구성 |
| 이번 정리 작업 | 선별 코드 공개 준비, 기술 설명, 검증 수준 구분, 재개 계획 |

각 변경의 작성자·작성 시점 전체를 복원한 자료는 없습니다. 원본 샘플에서 제공한 검출·카메라·자세 추정 기능과 프로젝트의 콘텐츠·연출 구성을 구분해 읽습니다.

## 범위

보존 개발본은 Unity 프로젝트이며 이 자료는 그중 주요 코드와 설명만 담습니다. 프로젝트의 이전 이름은 CREKI입니다. 2025-12-13을 개발 기준일로 삼고 후속 개발을 재개할 예정입니다. 정리일은 2026-11-26입니다.

손으로 현실 물건을 움직이는 경험을 목표로 하지만, Unity 손 추적·가상 Grab·영구 공간 앵커·AI 콘텐츠 편집 기능이 구현됐다는 근거는 이번 검토에서 확인하지 않았습니다.

시연 영상과 성능 측정 결과는 이 자료에 없습니다. 소스에 기능 경로가 있다는 사실을 실기기 검증 완료로 해석하지 않습니다. 현재 상태는 [구현 상태](IMPLEMENTATION_STATUS.md)를 참고하세요.
