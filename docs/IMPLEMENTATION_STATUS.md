# 구현 상태

기준 개발 상태: 2025-12-13까지 개발된 것으로 지정한 보존본. 검토일: 2026-11-26.

| 항목 | 확인 수준 | 남은 확인 |
|---|---|---|
| 카메라 초기화와 권한 대기 | 코드 존재 | 거부·실패·복귀 시 동작 |
| ArUco 검출과 자세 추정 | 코드 존재 | 실제 기기에서 이동·회전·정합 |
| ID 0/1 콘텐츠 연결 | 보존 씬·코드에서 확인 | 두 마커 동시 표시 및 ID 혼동 여부 |
| 위치·회전 보간 | 코드 존재 | 떨림과 추종 지연 |
| 스케일 등장·퇴장 | 코드 존재, 정적 결함 후보 | 전체 검출 소실·재등장 |
| 인트로 UI | 코드·보존 씬에서 확인 | 한글 출력과 Bounds 경고 |
| APK와 현재 소스의 일치 | 미확인 | 빌드 추적·비교 필요 |
| Unity 컴파일·Android 빌드·Quest 실행 | 이번 준비에서 미수행 | 의존성 복원 후 실행 필요 |
| 성능 개선 | 계획만 존재 | 변경 전후 동일 조건 측정 |

공개 준비본에는 주요 C# 3개만 복사했습니다. 씬·설정에 대한 설명은 보존 개발본의 검토 기록이며, 그 파일이 이 폴더에 들어 있다는 의미는 아닙니다. 실행 파일이나 시연 영상을 제공하지 않습니다.

전체 마커 소실 처리의 조기 반환 문제를 포함해 기존 런타임 코드는 수정하지 않았습니다. [문제 해결 계획](TROUBLESHOOTING.md)과 [재개 순서](REDEVELOPMENT_ROADMAP.md)를 따릅니다.
